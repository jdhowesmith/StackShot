# STACKSHOT

Marketing + shop site for **STACKSHOT** — Flip. Throw. Clear.

Next.js (App Router) · TypeScript · Tailwind CSS  
Target domain: [stackshot.ca](https://stackshot.ca)

## Brand

| Role | Colour | Hex |
| --- | --- | --- |
| Primary | Emerald | `#0B3D2E` |
| Accent | Gold | `#C9A227` |
| Base | Charcoal | `#1A1A1A` |
| Type | Off-white | `#F5F2E8` |

## Getting started

```bash
cd /workspace/StackShot
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Production build

```bash
npm run build
npm start
```

## Pages

- `/` — marketing home (hero, sales video, how it plays, product strip, what’s in the box)
- `/shop` — Full Game Kit (C$49.99), Starter Set (coming soon), Paper Boards Add-on ($4.99) with client-side cart (localStorage)

Brand images and `STACKSHOT-sales-web.mp4` live in `public/assets/`.
